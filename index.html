LogService

Log ingestion & query service

Ingests high volumes of structured logs into PostgreSQL, range-partitioned by week, and serves filtered queries with keyset pagination plus time-bucketed aggregates.

A per-minute rollup table, written in the same transaction as each ingest, cut worst-case aggregation p95 from about 8 s to about 1 ms at 1M rows. Expired data goes by dropping whole partitions instead of running DELETE.

Pipelined RISC Processor

32-bit predicated processor

A five-stage pipeline with 32 registers and separate instruction and data memories. Forwarding resolves data hazards, load-use hazards stall, and control-flow instructions kill the instructions behind them. Each instruction runs only when its predicate register is non-zero.

Verified in simulation with test programs covering arithmetic, memory access, predication, jumps, and CALL/JR.

SecureChannel

Peer-to-peer encrypted chat

Every cryptographic primitive is written from its RFC or FIPS specification, with no crypto library in the core: SHA-256, HMAC, HKDF, ChaCha20-Poly1305 and X25519, plus SHA-512 and Ed25519 as bonus work.

Peers authenticate with a pre-shared key, then chat and send files over TCP from a command line or a tkinter GUI.
